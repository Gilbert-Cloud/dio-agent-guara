# dio-agent-guara
Peguei o DIO Agent e criei o Guará, uma especialização em segurança. Ele analisa vulnerabilidades como um profissional: pergunta o contexto, classifica em CWE/OWASP/MITRE e fecha num laudo com impacto, probabilidade e severidade. Tem skill, base de conhecimento e um lab de SQL Injection. Rodei no Antigravity.
